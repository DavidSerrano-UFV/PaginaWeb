# Documento Detallado de Diseño (DDD)
## Proyecto: Página Web Personal – Fundamentos de la Ingeniería Informática

---

## 1. Descripción del trabajo

Este proyecto consiste en el diseño y desarrollo de un sitio web personal utilizando
exclusivamente tecnologías web estáticas (HTML y CSS). El objetivo principal del trabajo
es documentar y demostrar los conocimientos adquiridos a lo largo de la asignatura
Fundamentos de la Ingeniería Informática, así como reflejar mi progreso académico,
intereses y competencias dentro del Grado en Ingeniería Informática.

El sitio web presenta una estructura clara y coherente, con un sistema de navegación
común que permite acceder fácilmente a todas las secciones del proyecto.

---

## 2. Estructura del sitio web

El proyecto sigue el arquetipo propuesto en el enunciado de la práctica:

- Página principal (`index.html`), ubicada en la raíz del proyecto
- Carpeta `public` que contiene el resto de páginas HTML:
  - Sección "About me"
  - Sección temática
  - Sección de grado
  - Página específica de la asignatura Fundamentos de la Ingeniería Informática (FII)
  - Página de contacto
  - Página de red con enlaces a compañeros
- Carpeta `css` con un único archivo de estilos común a todas las páginas
- Carpeta `images` que almacena todas las imágenes utilizadas en el sitio web

Esta organización facilita la comprensión del proyecto, el mantenimiento del código y
la correcta gestión de rutas relativas entre archivos.

---

## 3. Tecnologías utilizadas

Las tecnologías empleadas en el desarrollo del proyecto son las siguientes:

- **HTML5**, utilizado para la estructuración semántica del contenido
- **CSS3**, empleado para el diseño visual y la presentación de las páginas
- **Git y GitHub**, utilizados para el control de versiones y la publicación del sitio web

---

## 4. Problemas durante el desarrollo

Durante el desarrollo del proyecto se presentaron diversas dificultades, entre las que
destacan:

- La organización inicial de la estructura de carpetas y archivos
- La correcta gestión de rutas relativas entre páginas HTML
- El ajuste del diseño visual para mantener una estética coherente en todas las secciones

Estos problemas se resolvieron mediante pruebas iterativas, revisión del código,
validación de los archivos HTML y CSS, y consulta de documentación oficial.

---

## 5. Conclusiones

La realización de este proyecto ha permitido consolidar los conocimientos fundamentales
sobre desarrollo web estático, comprender la importancia de una correcta estructuración
del proyecto y adquirir una primera experiencia práctica en la documentación técnica
mediante el uso de archivos Markdown.

Asimismo, el trabajo ha servido como introducción al uso de GitHub como herramienta
profesional para el control de versiones y la publicación de proyectos web.

Cabe destacar que, aunque cuento con formación previa como Técnico Superior en
Desarrollo de Aplicaciones Multiplataforma, la realización de este proyecto ha resultado
especialmente útil para repasar y afianzar conceptos fundamentales de HTML y CSS,
así como para aplicar buenas prácticas en la estructuración de proyectos web.
Este trabajo ha permitido consolidar una base sólida que será de utilidad en
asignaturas posteriores del grado.

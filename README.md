# Documento Detallado de Diseño (DDD)
## Proyecto: Página Web Personal – Fundamentos de la Ingeniería Informática

---

## 1. Descripción del trabajo

Este proyecto consiste en el diseño y desarrollo de un sitio web personal utilizando
exclusivamente HTML y CSS. El objetivo principal es documentar y mostrar los conocimientos
adquiridos a lo largo de la asignatura, así como reflejar mi progreso académico y competencias
en el ámbito de la ingeniería informática.

El sitio web está compuesto por varias secciones interconectadas mediante un sistema de
navegación común, siguiendo una estructura clara y coherente tanto a nivel visual como
funcional.

---

## 2. Estructura del sitio web

El proyecto sigue el arquetipo propuesto en el enunciado:

- Página principal (`index.html`)
- Sección "About me"
- Sección temática
- Sección de grado
- Página específica de la asignatura FII
- Página de contacto
- Página de red con enlaces a compañeros

Todas las páginas HTML se encuentran en la carpeta `public`, mientras que los estilos se
centralizan en un único archivo CSS externo.

---

## 3. Tecnologías utilizadas

- HTML5 para la estructura del contenido
- CSS3 para el diseño y la presentación visual
- Git y GitHub para el control de versiones y publicación del sitio web

---

## 4. Problemas durante el desarrollo

Durante el desarrollo del proyecto surgieron diversas dificultades, entre ellas:

- Organización inicial de la estructura del proyecto
- Ajustes de diseño responsive
- Gestión de rutas relativas entre carpetas

Estos problemas se resolvieron mediante pruebas iterativas, validación del código HTML/CSS
y consultas a la documentación oficial.

---

## 5. Conclusiones

Este proyecto ha permitido consolidar los conocimientos fundamentales de desarrollo web
estático, comprender la importancia de una buena estructura de proyecto y adquirir
experiencia en el uso de GitHub como herramienta profesional.

Además, ha servido como introducción práctica a la documentación técnica mediante el uso
de archivos Markdown.
